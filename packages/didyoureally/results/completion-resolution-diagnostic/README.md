# Superseded general-instruction experiment

This experiment strengthened completion and context resolution in the main prompt and clarified the existing repair wording. Both models scored 11/16 on the known vague cases. It was not the final implementation.

The replies showed that action mappings were still lost during argument repair. A dedicated shorter repair instruction was evaluated next in [focused repair](../focused-repair-diagnostic/report.md). These sets were used for development; no fresh completion validation outputs were used for tuning.
